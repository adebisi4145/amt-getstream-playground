# @amt/web

React 19 + TypeScript + Vite client for the playground.

Run these from the repo root:

| Command | What it does |
| --- | --- |
| `npm run dev` | Start the dev server at http://localhost:5173 |
| `npm run build` | Type-check and build to `apps/web/dist` |
| `npm run lint` | Run ESLint |

To run a command that has no root script, use `npm run <script> --workspace=apps/web`, e.g. `npm run preview --workspace=apps/web`.
